# 🧮 Calculator

A simple and interactive **Calculator Web Application** built using **HTML, CSS, and JavaScript**. This project performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

## 🚀 Features

* Addition (`+`)
* Subtraction (`-`)
* Multiplication (`*`)
* Division (`/`)
* Clear (`C`) button
* Calculate result (`=`) button
* Error handling for invalid calculations
* Simple and clean calculator interface
* Responsive basic layout

## 🛠️ Technologies Used

* **HTML5** – Structure of the calculator
* **CSS3** – Styling and layout
* **JavaScript** – Calculator functionality and calculations

## 📂 Project Structure

```text
Calculator/
│
└── calculator.html
```

## ⚙️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/praveenmatti/calculator.git
```

2. Open the project folder.

3. Open `calculator.html` in any web browser.

## 💡 How It Works

* Click the number buttons to enter numbers.
* Select an arithmetic operator.
* Enter another number.
* Click the `=` button to calculate the result.
* Click `C` to clear the display.

The calculation is handled using JavaScript.
